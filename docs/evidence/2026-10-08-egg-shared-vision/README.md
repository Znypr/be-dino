# Egg design review evidence, 2026-10-08

These are actual Blender-rendered review images, archived to support the [shared egg appearance vision](../../39-egg-appearance-shared-vision.md). They are not runtime sprite sheets, a claim of natural reward frequency, or proof of Roblox uploads/integration.

| File | Meaning / approval scope |
|---|---|
| `eight-patterns.jpg` | Eight authored patterns including blank; locked silhouette and illustrated shell direction |
| `color-mixes-and-rare-examples.jpg` | Intentionally forced two-color ratios, double blue, vivid red and double black; exact rarity weights are provisional |
| `basic-conditions.jpg` | Cracked, Dirty and Normal review renders; Cracked/Dirty overlay direction accepted |
| `anime-aura-drafts.jpg` | Latest seven surrounding smoke/anime-wisp mutation renders with retained stone tile and grassy background; pending owner visual approval |

Rainbow/Astra recolors and shimmer/constellation drafts are intentionally excluded from the current visual gallery: the owner deferred their condition effects for rework. Earlier realistic shell, shell-mounted mutation marks and flat-ring auras are historical iterations, not current style authorities.

`manifest.json` records file sizes, dimensions and SHA-256 hashes plus editable source lineage. The local projects live under the author's `Premium_Egg` workspace. Full `.blend` sources, 1024 masters and individual 512 RGBA export packs have **not** been copied into GitHub by this documentation pass; the manifest paths are local lineage, not repository download links.

Archived machine-readable evidence:

- `pattern-validation.json`: dimensions, transparency and canonical mask comparison from the pattern batch.
- `aura-render-validation.json`: latest seven 512 RGBA effect passes; partial transparency and average alpha in a shell-center region. The nonzero center alpha is intentional foreground smoke, not an opaque replacement egg. Original individual PNGs remain local.
- `scene-integrity.json`: original canonical egg vertex hash matched, camera matrix maximum difference zero.
- `provisional-color-authoring-config.json`: authoring colors, weights and draw rules. The file's historical phrase "eight accepted patterns" refers to the selected authored set, not proof of runtime acceptance. Its uniform pattern weights and exact color odds are demonstration defaults, not public balance approval.

Preview JPEGs are presentation evidence and have opaque backgrounds. True-alpha assertions apply to the individual effect PNGs described by the validation records, not to these JPEGs. The smoke is procedural static volume/material geometry in Blender; no animated simulation or optimized runtime VFX is certified. Gold/Diamond, shop auras/trails, Shiny/BIG and species mechanics remain separate systems with their own existing documentation.
