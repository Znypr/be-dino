# Design board pictures (2026-11-15)

Concept sheets for the world redesign (BD-1208, docs/241). ChatGPT concept art made from our own Studio screenshots; reference for Blender modelling only, never final art in the game.

- `sheet-food-chatgpt.jpg`: food as things in the world (berry bushes, fruit trees, nest and eggs, amber rock, golden drumstick).
- `sheet-vegetation-chatgpt.jpg`: zone trees (broadleaf, pine, palm, giant landmark tree), bushes and clumps, ground plants per zone.
- `sheet-decoration-chatgpt.jpg`: small props (boulders, log, fence, lantern), village (signpost, hatchery hut, food stall, rope bridge), landmarks (fossil, waterfall arch, volcano, spawn plaza).
- `dino-lineup.png`: the V3 dino models today. `ui-today.jpg`: UI screens in the game today.

All pictures are also on the owner's private design board (pages: overview, style rules, dinos, food, vegetation, decoration, map, UI menus).
