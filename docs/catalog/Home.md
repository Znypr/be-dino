# Be Dino! team catalogue

This is the one place where everyone (owner, helpers, Codex) reads what the game contains today: which dinosaurs, looks, items and foods exist, their pictures, what is missing and the chances. It is only for the team. Agents: read this page first when you make art or content.

Generated by `tools/build_catalog.py` from the game code. Do not edit by hand: change the code, then run `python tools/build_catalog.py`.

Every item is a section with an anchor on its page (never a page of its own). Each page starts with a contents list. A STATUS table per category shows: picture or icon present, asset id bound, mask present, and where the odds come from.

<a id="how-to-add"></a>
## How to add art or content

1. Find your item under **Missing** below. It names the exact folder and file name.
2. Put the file there (and add one line to [docs/77](../77-asset-registry.md)).
3. Run `python tools/build_catalog.py` and commit `docs/catalog/` together with your change. CI fails when the catalogue is out of date (`python tools/verify_catalog.py`).
4. Binding the uploaded id into the code is a separate step (`tools/bind_assets.py`).
