### How the six missing ids and boxes were found (2026-10-18, second binding round)
- **Nothing was invented.** The Model ids are not stored on Place 1 instances, so every Model in the owner's **Creator Hub > Creations > Models** (180 "Roblox Generated Object" entries from 2026-10-15 on, read only, nothing changed) was loaded in the scratch Studio with `InsertService:LoadAsset` (Edit mode, a temporary folder, destroyed afterwards) and its part mesh ids were compared with the part mesh ids of the Place 1 models in `Workspace > Silly secret dinos v3`. An id counts only when the part count, the part names and **every part mesh id** are equal. Proof table: [evidence/2026-10-18-secret-bind](evidence/2026-10-18-secret-bind/README.md).
- **Control:** the Foxosaurus v2 id loaded to 3.84 x 8.37 x 8.00 (the recorded 3.8 x 8.4 x 8.0). The scratch place itself still holds the OUTDATED v1 fox with the beanie (the saved copy is older than the owner's live Place 1), which the same method also recognised (119604460832523): a reminder that the scratch place is not the live Place 1.
- **The boxes** are the models as `LoadAsset` returns them (growth scale 1, the convention of the 22 species and of the fox). The Place 1 showcase copies of Chickosaurus, Pigeon, Dodo, Duck and Penguin are scaled up to a common height of 7.67 studs (3.3 to 3.55 times) and are NOT the game size; the Budgiesaurus copy is unscaled. The head length is still an ESTIMATE (22% of the length) for every secret: no head part was measured.

## 2. What the playtest does now (owner directive)
- `tools/release_profiles.py`: the `playtest` profile **sets** `SecretSpeciesEnabled = true`; the `default` profile **requires** it false (it moved out of the rules shared by every profile). `src/shared/Config.luau` still says `false`: the flag is rewritten into the generated place only.
- The roll only picks among species whose slot holds a real id (`Secret.readyIds`). **All seven slots now hold a real id**, so a secret hit can be any of the seven, by weight (Chickosaurus 20, Pigeon 20, Duck 18, Dodo 14, Penguin 12, Budgiesaurus 10, Foxosaurus 6 of 100; PROVISIONAL).
- **What a tester can find:** any of the seven secrets, from **free** eggs only: eggs earned in a run, and eggs from a free bonus nest. A flat **0.5% chance per egg** (PROVISIONAL), the same for a 1-egg and a 400-egg run, and a hit on an egg that fails (a Cracked egg) is lost. In a 40-egg five-minute run that is about 1 run in 9 to 1 run in 5 (11% with 40% of the eggs failing, 18% if none fail); a 400-egg run nearly always has one (86% if none fail). The hatch shows the calm "Secret" line, a banner "Secret find! You hatched a <name>!" (others read "Sam found a secret dino!" without the name), the Index card turns from "???" into that dino, and it can be equipped and played as a Compy-sized dino (Ground, Water for the Penguin, Fly for the Budgiesaurus). The Egg Odds panel says "A tiny chance of a secret dino in free eggs" for free eggs only.
- **Never from a shop egg or a paid egg** (docs/43): unchanged, proven again with the shipped roster in `verify_secret_species` part B (a crystal-shop egg carries no roll even at a forced 100% chance). The paid lines (`CrystalPacksEnabled`, `PaidRandomItemsEnabled`) stay off in every profile.
- The Index shows "0 / 7 secrets found" and seven cards, each a silhouette until found. With the 0.5% chance a tester needs a long session or many runs to complete it; the playtest notes should say so. Whether the Water (Penguin) and Fly (Budgiesaurus) classes behave well as a Compy-sized pet is NOT seen in Studio.

## 3. Why this is allowed by the rules
- [157](157-playtest-profile-newest-features.md) kept the flag off only because "all seven model slots are empty". That reason no longer holds for one slot.
- [149](149-secret-species.md) SS6: a secret cannot roll or hatch while its slot is empty (`modelReady`), so a partial roster is part of the design, not a hack. No code of the rules changed for this decision.
- Pace: nothing about normal eggs changes (with the flag on, a run egg gets one extra draw only when a model is ready; the golden hash of 16,000 flag-off rolls is unchanged).

## 5. Measuring a model in Studio (for whoever has a free window)
Insert the model at the origin (the same way the game loads it: `InsertService:LoadAsset(<Model id>)`), then read the box of its mesh parts at scale 1. The repo method is BD-471; the short form:
```lua
local container = game:GetService("InsertService"):LoadAsset(ASSET_ID)
local model = Instance.new("Model")
for _, part in container:GetDescendants() do if part:IsA("MeshPart") then part.Parent = model end end
model.Parent = workspace
local _, size = model:GetBoundingBox()
print(("%.2f x %.2f x %.2f"):format(size.X, size.Y, size.Z)) -- width x height x length, the model faces -Z
local head = model:FindFirstChild("head_geom", true) or model:FindFirstChild("head", true) -- optional: its length for --head-length
```
Width is the X size, height the Y size, length the Z size of the model as generated (the same convention as the 22 species rows). Delete the model afterwards.
