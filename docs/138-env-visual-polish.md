# 138 Island environment visual polish (BD-460, 2026-10-16)

Owner feedback on a screenshot of the island in Realistic (Future) lighting at max quality: the grass shows strong repeating dark waves that out-shout the dinosaur, the greens are over-saturated, some treetops clip and some ground is near black, and the dino blends into the green. Built on top of PR #302 (clear daylight, no haze); nothing here adds haze. Labels: **CODE** = what this PR changes, **STUDIO PENDING** = needs the lead's eyes.

## 1. Root cause of the grass striping
`MaterialService.GrassName = BeDino_Meadow` (`resources/world-materials.rbxmx`, generated by `tools/bind_visual_assets.py` from `resources/visual-upgrade-bindings.json`) replaces the terrain Grass look with an AI-generated PBR set: colour 94202355146046, normal 102603392874381, roughness 82962110810713, metalness 94175885618888, tiled every **20 studs**. The prompt asked for "broad soft grass tufts ... muted cool shadows", so the colour map has **large dark baked shadow blotches**, and the three extra maps turn the hair-like blade detail into directional streaks and a sheen under the Future sun. A 20-stud tile puts one blotch lattice cell every 10 to 20 studs in the foreground, which is the repeating dark wave. The old screenshot evidence (`docs/evidence/2026-10-16-quality-gates/island__meadow_noon.jpg`, `.../2026-10-16-tiers/triceratops-all-tiers-island.jpg`) shows exactly this, plus dark teal patches where terrain `LeafyGrass` (62,124,78) mixes in. `Terrain.Decoration = true` (`IslandTerrain.build`) is a secondary suspect, left on.

It is an art texture, so nothing was redrawn in code. Existing properties only: unbind the maps, shrink the tile. The new art task is `TODO_meadow_grass_texture_v2` in [77](77-asset-registry.md).

## 3. Rules kept
- **No haze** (owner 2026-10-16, [115](115-decisions-log.md)): a "subtle distance haze" suggestion from the feedback was **skipped**. `tools/verify_env_polish.py` asserts the atmosphere numbers stay .1 / .3 / 0 and the clear look adds no density, haze, bloom, DoF or rays.
- **Phone cost not worse:** the world changes are data only (no new parts; one tint per mesh template, not per prop). The contact shadow is 3 parts for the local dino plus at most 2 others on a phone (Tablet 4, Desktop 6), Lite halves and Off drops the others, one raycast each, no textures. Existing `EffectsLod` and the Effects setting are respected through `ContactShadowRules.maxOthers`.
- **Luminance band** island 0.35 to 0.75 ([114](114-handbook.md) s6.1): sun is a little lower but the ambient floor is higher; re-measure with `tools/qa/luminance.py` (STUDIO PENDING, the last measured meadow noon was 0.387, close to the lower edge).
- Vibe words ([114](114-handbook.md) s0): calmer greens and matte grass, but still colourful; the clear grade stays slightly positive.

## 4. Studio checklist for the lead (Future lighting, max quality, desktop and phone)
1. Grass: no repeating dark waves, no sheen; fine matte variation; no visible tile lattice at the horizon (tile is now smaller: if a grid shows, raise `tile` back to 16 in the bindings json).
2. If streaks remain: set `Terrain.Decoration` to false in `IslandTerrain.build`, then, if still bad, set `GrassName` to the built-in Grass (empty `color` for BeDino_Meadow in the bindings json) and wait for the new texture (77, `TODO_meadow_grass_texture_v2`).
3. No dark teal ground patches; treetops not clipped; crowns read leaf green, not mint. If `SurfaceAppearance.Color` has no effect on a generated mesh, the tone silently skips (pcall); then use the grade only.
4. Collectibles still vivid next to the calmer grass; the dino has a soft shadow on flat ground, on a slope, and it shrinks and fades in a jump.
5. Weather events still ramp to their own look and return to the new clear base (Brightness 1.8).
