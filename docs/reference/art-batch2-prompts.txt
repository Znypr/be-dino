Common block (opens the first message of every chat; the chat name is the first words):
  "Chat name: BeDino Art Batch 2 - <CATEGORY> icons. Hi! I make icons for Be Dino!, a calm bubbly Roblox dinosaur game for young children. Please read the game handbook first if you can browse: https://github.com/Znypr/be-dino/blob/main/docs/114-handbook.md (raw text: https://raw.githubusercontent.com/Znypr/be-dino/main/docs/114-handbook.md), sections 4 (design language) and 5 (colour palette). In case you cannot open it, these are the key rules: chunky rounded shapes, a thick dark outline (about 3 px at 64 px size), soft matte cartoon finish with gentle highlights from the top left, saturated warm friendly colours, a clear silhouette that still reads at 64 px, one single idea per cell, no text, no letters, no numbers, no gradients that fight the outline, never scary or sharp. Match the style of the attached image(s). Palette: gold #FFD22B, green #5DED1F, blue #2ECEFF, purple #C256FF, red #F73930, dark outline #0D0F14; crystals and gems are always AMBER or golden yellow, never blue."
Every sheet: landscape, clean grid (equal cells, thin even gaps), every cell on the same flat plain light-grey background (#E8E8E8), no cell frames, nothing touching the cell edges, no shadows outside the object, no text. Rows = icons, columns = 4 design ideas per icon.
