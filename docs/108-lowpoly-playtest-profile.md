## NPC predators (BD-324, 2026-10-16)
With `Config.LowPolyDinos` on, `NpcPredatorService` builds each wild predator from the species low-poly model (`LowPolyDinos.clone`, then `ScaleTo` the 1.0 to 1.3 NPC size, same part rules) welded to the Humanoid root with `ResourceWeld`. The dark "wild" look is a thin translucent shell per textured part (`Shared/NpcLowPoly`: colours, shell settings, model-selection and cue rules, tested offline). No EditableImage is used for NPCs, so the 80 MiB image budget is untouched.
- Findings in Studio: `MeshPart.Color` is ignored on a textured MeshPart, and `SurfaceAppearance.ColorMap` cannot be written from a game script (capability Plugin). The shell approach avoids both.
- Animation: `LowPolyAnimator` also walks `workspace.BeDinoNpcs` (only exists with combat on), 20 Hz within 80 studs, same `LowPolyPose` functions as player rigs; new phases `windup` (lean back) and `bite` (lunge + snap) are driven by the replicated `NpcCue` and `BiteSeq` attributes. `NpcMotion` skips its bob for models flagged `NpcLowPoly` and still fades them out.
- Fallback: flag off, unmapped species, template missing or a build error keeps the legacy `DinosaurVisual` NPC (a warning names the species).
- Evidence (own temp copy of the playtest build, CombatEnabled true in the copy only): `evidence/2026-10-16-npc-lowpoly/02-after-lowpoly-wild-spinosaurus.jpg` (low-poly dark Spinosaurus next to a low-poly player Compy), `01-before-legacy-npc-fallback.jpg` (templates deleted, the legacy NPC fallback; this is the pre-change look). Poses: idle weld C1 values vary over time; windup raises the body offset smoothly, bite moves the head (+0.6 forward) and pitch. Honest limit: the test player was not attacked, so the full chase/windup/bite sequence was not watched live.
