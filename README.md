**Stage:** planning complete; implementation not started. **Updated:** 2026-09-17.
**First milestone approved by Znypr:** private community test, cute ground-based dinosaurs, small complete progression loop.

No game code, assets, Roblox place or playable build exists yet.
Numbers in design documents are proposals unless explicitly marked approved.
Use original code, models, interface and sounds; reference screenshots are research evidence, not assets to ship.
